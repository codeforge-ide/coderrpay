# CoderrPay

✨ CoderrPay brings developers, projects, and organizations together to collaborate, solve bounties, and get rewarded. 

🚀 Build together. Ship faster. Earn smarter.

- Connect with others
- Find and solve bounties
- Collaborate and get paid
- **Support developers with sBTC micropayments**

Simple. Community-first. Make something awesome. ❤️

---

## 🎯 Features

- **Multi-Provider Authentication**: Civic (GitHub + Web3), Appwrite, and fallback Web3 wallet support
- **Turnkey sBTC Integration**: Send and receive sBTC payments on Stacks testnet with embedded wallets
- **Developer Support**: Tip developers instantly with frictionless micropayments
- **Bounties & Grants**: Discover and solve development challenges
- **Hackathons**: Join competitions and win rewards
- **Projects**: Showcase your work and collaborate
- **Organizations**: Team collaboration features

## 💰 Monetization with sBTC

CoderrPay includes a practical monetization solution powered by Turnkey's embedded wallet SDK:

- **Instant Wallet Creation**: Create a secure sBTC wallet using passkeys (Face ID, fingerprint)
- **Frictionless Payments**: Support developers with sBTC tips without leaving the app
- **Stacks Testnet**: Safe testing environment for all transactions
- **Transaction Tracking**: Full history with block explorer integration

For detailed information, see [TURNKEY_INTEGRATION.md](./TURNKEY_INTEGRATION.md).
